A Hinglish-first reminder application...

## ✨ Features

- Natural Hinglish reminder input
- Hindi + English mixed commands
- Smart date/time extraction
- One-time & recurring reminders
- Live countdown
- Snooze
- Browser notifications
- Alarm sound
- Reminder history
- localStorage persistence
- Fully responsive
- Zero dependencies

## 🧠 How it works

User input
     ↓
Hinglish Parser
     ↓
Date / Time / Task extraction
     ↓
Confirmation
     ↓
localStorage
     ↓
Countdown Engine
     ↓
Alarm + Notification
